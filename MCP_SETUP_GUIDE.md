# Supabase MCP Setup Instructions for drivendatadynamics@gmail.com

## Overview
This guide will help you set up Supabase MCP (Model Context Protocol) integration so that AI assistants can directly interact with your Supabase database and provide full access for drivendatadynamics@gmail.com.

## Prerequisites
- Node.js 18+ installed
- A Supabase project
- Your Supabase project credentials

## Step-by-Step Setup

### 1. Configure Supabase Credentials

1. Go to your Supabase dashboard: https://supabase.com/dashboard
2. Select your AI Calling Center project
3. Go to Settings → API
4. Copy the following:
   - Project URL (e.g., https://abcdefgh.supabase.co)
   - service_role secret key (starts with eyJ...)

5. Edit the `.env` file in your project root and replace:
   - `SUPABASE_URL=https://your-project-ref.supabase.co` with your actual Project URL
   - `SUPABASE_SERVICE_ROLE_KEY=your_service_role_key_here` with your actual service_role key
   - Update the `SUPABASE_JWKS_URL` to match your project URL

### 2. Create Personal Access Token for MCP

1. Go to https://supabase.com/dashboard/account/tokens
2. Click "Generate new token"
3. Name it: "AI Assistant MCP Server"
4. Click "Generate token"
5. **IMPORTANT: Copy the token immediately** (you won't see it again)
6. Add it to your `.env` file: `SUPABASE_ACCESS_TOKEN=your_personal_access_token_here`

### 3. Test Your Setup

Run the MCP setup script:
```bash
node scripts/setup-mcp.js
```

This will:
- Verify your environment variables
- Extract your project reference ID
- Generate the MCP configuration
- Test the MCP server connection

### 4. Configure Your AI Assistant

#### For Claude Desktop:
1. Open: `%APPDATA%\Claude\claude_desktop_config.json`
2. Add the configuration provided by the setup script
3. Replace `YOUR_PERSONAL_ACCESS_TOKEN_HERE` with your actual token
4. Restart Claude Desktop

#### For Cursor:
1. Open Cursor settings
2. Go to MCP configuration
3. Add the Supabase MCP server with the configuration from the setup script

#### For Other MCP Clients:
Use the JSON configuration generated by the setup script.

### 5. Bootstrap drivendatadynamics@gmail.com User

Once your API server is running, bootstrap the user:

```bash
# Start your services first
pnpm dev:all

# Then in another terminal, run the bootstrap script
node scripts/quick-setup.js
```

This will ensure drivendatadynamics@gmail.com has:
- Access to the "AI Calling Center" tenant
- OWNER role (highest permissions)
- Full access to all tenant data

### 6. Test MCP Integration

Ask your AI assistant questions like:
- "What tables are in my Supabase database?"
- "Show me the schema for the contacts table"
- "List all tenants in the system"
- "Generate TypeScript types for my database"

## Security Configuration

The MCP server is configured with:
- `--read-only` flag: Prevents accidental data modifications
- `--project-ref` flag: Scopes access to your specific project
- Limited feature groups: Only enables necessary tools

## Troubleshooting

### Environment Variables Not Loading
- Ensure `.env` file is in the project root
- Check that all required variables are set
- Restart your terminal/IDE after setting variables

### MCP Server Not Starting
- Verify Node.js version (18+ required)
- Check that your Personal Access Token is valid
- Ensure project reference ID is correct

### Authentication Issues
- Verify your service role key is correct
- Check that the user bootstrap script ran successfully
- Ensure RLS policies are properly configured
