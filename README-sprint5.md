# AI Calling Center - Sprint 5: Dashboard UI + Recharts Analytics

This document outlines the implementation of Sprint 5, focusing on creating a data-driven dashboard with key performance indicators and visualizations.

## 1. Setup

Install the required libraries for charting and maps:

```bash
npm install recharts leaflet react-leaflet
npm install -D @types/leaflet
```

## 2. End-to-End Testing

1.  **Login:** Access the application and navigate to the dashboard.
2.  **KPIs:** Verify that the four main KPI cards are displayed with data.
3.  **Charts:** Check that the Conversion Funnel and Call Time Heatmap are rendered correctly.
4.  **Map:** Ensure the Geo-Map is displayed with clustered data points.
5.  **Filters:** (If implemented) Test the date range and campaign filters to see if the charts update dynamically.
